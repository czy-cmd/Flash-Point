# FLASHPOINT PROTOCOL · 闪点协议

点击式实时抢修游戏。玩家扮演电网抢修员，在网格地图上点击移动，抢在 AI 前面修复不断出现的电网闪点。

纯前端：HTML + CSS + 原生 JavaScript，无框架、无 npm、无后台、无联机。

## 运行

直接双击 `index.html`，或用任意静态服务器（必须用服务器打开才能使用 `localStorage` 存档）：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 部署到 GitHub Pages

1. 把整个 `flashpoint-protocol` 文件夹推到 GitHub 仓库（可以只放这个文件夹）。
2. 仓库 Settings → Pages → Source 选择 `Deploy from a branch`，分支选 `main`，
   目录选 `/ (root)`（若文件夹在根目录下，则选 `/docs` 或把文件夹内容移到根目录）。
3. 等 1—2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

不需要构建步骤，不需要 `.nojekyll`（没有下划线开头的文件）。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架：加载页、主菜单、模式选择、插件设置、游戏、结算、弹窗 |
| `style.css` | 样式：深色 / 浅色 / 冷色三套主题变量与布局 |
| `data.js` | 数据表：模块级别、模块效果、系统插件、50 个外置插件、模式 |
| `core.js` | 状态 / 存档 / 寻路 / Canvas 渲染 / 固定时间步主循环 |
| `ani.js` | 动画引擎：缓动函数与时长移植自 PCL2 的 ModAnimation |
| `modes.js` | 常规五种模式玩法：移动、读条、AI、连击、模块装配、事件插件 |
| `pid.js` | PID 进程模式：进程生命周期、CPU / 内存调度、任务管理器 |
| `loader.js` | 加载页：进度由真实启动步骤驱动，逐帧平滑推进 |
| `ui.js` | 界面逻辑：菜单、插件页、设置、开发者模式、结算 |

## 操作

- 点击相邻格：移动一步；点击远处格：自动寻路。
- 点击脚下的闪点：开始读条（也会自动走到闪点再读条）。
- 点击地图上的模块核心：进入 3×3 装配面板，按闪烁顺序点击。
- 点击模块槽：主动使用模块（消耗能量，积累热量）。
- 点击「短路」：让最近的 AI 减速。
- 对局中按 `ESC` 暂停 / 继续（也可用「重新开始」「结束本局」）。
- 其余操作用鼠标 / 触屏即可。

## 外观与设置

设置页可以切换：

- 音效、动画开关；
- 界面主题：深色 / 浅色 / 冷色（即时生效并记入存档）；
- AI 难度、单局时长；
- 开发者模式开关（开启需要密码，关闭不需要）；
- 重新加载：重新打开本页；
- 清除最高分 / 清除存档。

## 开发者模式

- 在设置里打开「开发者模式」开关，或在主菜单点击「日志 / command命令」，需要输入管理员密码。
- 源码编辑器有独立的二级密码。
- **密码不会显示在界面、输入框提示或命令帮助里**（输入框只显示「请输入密码」），代码里也只保存哈希。
- 关闭方式：设置里的开关直接关闭，或在命令台执行 `fp off dev`。
- 开发模式下 HUD 显示 `DEV` / `SRC`，成绩不计入最高分。

## 说明

- 规格来自《闪点协议》六份文档：游戏、准则、插件、级别、细节、PID。
- 外置插件上限 5 个，超出会提示；`system change` 对外置插件恒为 `false`。
- 存档键：`fp_settings` / `fp_progress` / `fp_highscores` / `fp_plugins_enabled` / `fp_plugins_custom` / `fp_daily`。
- 动画参数（缓动、时长、错峰节奏）参考 PCL2 的动画模块：页面逐元素上浮入场、按钮按压回弹、弹窗上滑淡入。
